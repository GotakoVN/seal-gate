# seal-gate

Standalone AI quality gate with a deterministic core and optional LLM review.

Use [USAGE.md](./USAGE.md) for the TypeScript, Python and CLI interfaces.
[Mandatory Property evidence](./docs/property-evidence.md) describes the trusted
verifier API, blocking mutation policy and independently reviewed equivalence.

Seal is the quality gate in the Orca harness family, alongside Pilotfish and
Hammerhead. The normal local file workflow requires no GitHub account.
This candidate is delivered through a reviewed local tarball; repository review,
local deployment and registry publication are separate states.
